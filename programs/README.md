# Your programs

What you make goes here, one folder per program or app:

```text
programs/
  CIRCLE/
    CIRCLE.txt        the source
    CIRCLE.hpprgm     built from it: the file that goes onto the calculator
```

Git ignores everything in this folder except this note, so what you make is
never part of the repository: a `git pull` or an `hpprime update` leaves it
alone, and none of it is published if you push.

An assistant working in this repository puts your programs here by itself;
[`AGENTS.md`](../AGENTS.md) tells it to.
