# Plan 02: `hpprime update`

Decision 3 of `11-CONTEXT.md`, approved by the user on 2026-09-26.

## What is known before building

- `git archive --format=zip HEAD`, which is how GitHub builds a branch's
  ZIP, wrote the commit's full hash as the archive's comment and put every
  file under one folder (`--prefix=hp-prime-kit-main/`): 1,009 entries,
  1.5 MB, on 2026-09-27. Whether GitHub's own ZIP does the same is seen in
  11-03.

## Tasks

1. **`hpkit/update.py`**, standard library only:
   - the ZIP from `https://github.com/JordiRigau/hp-prime-kit/archive/refs/heads/main.zip`,
     or from `--from FILE.zip`; the one folder every entry sits under is
     stripped;
   - refused where the kit's folder has `.git`: `git pull` instead;
   - nothing written inside `programs/`, nor to `.claude/settings.local.json`;
   - an entry that would land outside the kit's folder refuses the whole ZIP
     before anything is written;
   - a file written only when its bytes differ; nothing deleted. A file on
     disk that the new version lacks is listed, unless it is the person's
     (`programs/`, `settings.local.json`) or matches the new `.gitignore`,
     which is how the kit marks what it does not ship;
   - `--dry-run` says what it would do and writes nothing;
   - it reports files changed, added and unchanged, the listed files, and
     the commit when the ZIP's comment is one.
2. **`hpprime update`** in `hpkit/cli.py`, in `--help`, and its section in
   `docs/tools.md`; the README's table; step 1 and `programs/README.md` say
   how a download is updated.
3. **`tests/test_update.py`**, on a kit folder and ZIPs made in the test,
   no network: a changed file rewritten and an unchanged one not; a new file
   added; `programs/` and `settings.local.json` untouched though the ZIP
   carries both; a removed file kept and listed, an ignored one not listed;
   a clone refused; a ZIP reaching outside refused with nothing written;
   `--dry-run` writing nothing; the commit read from the comment. Added to
   `tests/run_all.py`, and the count of suites in the docs follows.

## Done when

`python tests/run_all.py` passes, and `hpprime update --from` a ZIP made by
`git archive` brings a copy of the kit to it.
