# Plan 01: lint after an edit, and the ledger

Proposals 4 to 6 of `12-CONTEXT.md`, approved by the user on 2026-09-29.

## Settled before building

- **Research point 3**: on 2026-09-29, a `.claude/settings.json` holding
  only `"env": {"HPPRIME_GATES": "1"}` was written in this session; the
  next Bash command saw `HPPRIME_GATES=1`, and so did Python started from it.
  So the tools can tell they run under the kit's settings, and the fallback
  of reading the agent's commands is not needed.

## Tasks

1. **`hpkit/gates.py`**:
   - `program_rel(path)`: `programs/.../X.txt` relative to the kit, or
     `None`; a `.txt` counts as PPL when it has a `BEGIN`;
   - the ledger, `.claude/hpprime-gates.json`: per file, the SHA-1 of the
     content each gate last read and whether it passed; the files edited
     since the end check last passed;
   - `record(path, gate, ok)`, which writes only when `HPPRIME_GATES` is
     `1`;
   - `post_edit(event)`: the hook for `Edit|Write|MultiEdit`. A PPL file in
     `programs/` is added to the edited files and linted; errors go to stderr
     with exit 2, warnings to `additionalContext` with exit 0, a clean file
     is silent; anything else is left alone.
2. **`lint` and `run` write the ledger**: `lint` per file, passed when that
   file has no error and reads as UTF-8; `run` per file, passed when the
   file loaded and at least one `--call` was given and every one answered.
3. **`hpprime hook post-edit`**, reading the event on stdin and writing
   UTF-8, so a finding with `→` or `μ` reaches Claude intact.
4. **`.claude/settings.json`**: the variable, and the hook in exec form,
   `python` with `${CLAUDE_PROJECT_DIR}/hpprime.py`, `hook`, `post-edit`.
   **`.gitignore`**: `.claude/hpprime-gates.json` and
   `.claude/settings.local.json`, which are the person's.
5. **`tests/test_gates.py`**, on a kit folder in a temporary directory and
   events made in the test: an error reaches stderr with exit 2 and is
   recorded failed; a warning goes as context and is recorded passed; a
   clean file is silent; a file outside `programs/`, a `.py`, and a `.txt`
   with no `BEGIN` are left alone; `lint` and `run` record only with the
   variable set; `run` with no `--call` does not pass. Added to
   `run_all.py`; `docs/tools.md` says what `hook` is.
